# Afinador (iOS)

Afinador de violão nativo em SwiftUI, sem anúncios.

## Gerar o .ipa
1. Crie um repositório no GitHub e envie esta pasta (branch `main`).
2. O workflow **Gerar IPA** roda sozinho (aba *Actions*). Ao terminar, baixe o artefato `Afinador-ipa`.
3. Instale com Sideloadly, AltStore ou TrollStore — eles assinam o app com o seu Apple ID.

O .ipa sai sem assinatura; a ferramenta de instalação faz a assinatura.
